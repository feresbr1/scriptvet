# Security Policy

Only the latest release and the website at https://feresbr1.github.io/scriptvet/ receive fixes.

## Reporting a vulnerability

Please report privately through [GitHub security advisories](https://github.com/feresbr1/scriptvet/security/advisories/new), not in a public issue. Examples:

- a crafted lockfile or script file that makes scriptvet execute code,
- `--write` corrupting or removing unrelated configuration,
- a malicious install script that scriptvet recommends allowing without marking it for review.

## Reporting a malicious package

Report it to npm (`npm report <package>` or https://www.npmjs.com/support) and to the [OpenSSF malicious-packages](https://github.com/ossf/malicious-packages) project.
